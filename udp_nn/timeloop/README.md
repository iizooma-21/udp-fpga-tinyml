| File | Purpose |
|---|---|

## Run mapper

**Recommended (from PowerShell):**

```powershell
wsl -e bash /home/hazem/run_timeloop_fixed.sh
```

**Inside WSL** (script sets PATH automatically):

```bash
cd ~/udp_timeloop
./run_mapper.sh all          # all three layers
./run_mapper.sh stem_conv    # one layer
```

If `timeloop-mapper` is not found, build it at `~/timeloop` or use the PowerShell command above.

Results go to `outputs/<layer>_mapper.txt` and `outputs/<layer>.stats.txt`.
Check the bottom of each `.stats.txt` for `Cycles`, `Utilization`, and `Computes`.

### Troubleshooting

**`env: bash\r: No such file or directory`**

The `.sh` scripts were saved with Windows line endings. In WSL:

```bash
cd ~/udp_timeloop
bash fix_crlf.sh
```

Or: `sed -i 's/\r$//' ~/udp_timeloop/run_mapper.sh`

**`timeloop-mapper: command not found`**

Timeloop is not on PATH. Use the PowerShell launcher (sets PATH automatically):

```powershell
wsl -e bash /home/hazem/run_timeloop_fixed.sh
```

**All layers show identical stats (13 cycles, 1040 computes)**

The mapper failed silently and copied stale stats. Re-run after fixing PATH/CRLF;
`run_mapper.sh` now errors instead of copying old results.

**`No such file or directory` for project path**

Use the symlink, not the Windows path with spaces:

```bash
cd ~/udp_timeloop    # not /mnt/d/Uni work/...
```

**Manual** (only if PATH is already set):

```bash
export PATH=$HOME/timeloop/bin:$PATH
export LD_LIBRARY_PATH=$HOME/timeloop/lib:$LD_LIBRARY_PATH
cd ~/udp_timeloop
timeloop-mapper udp_arch.yaml problem_stem_conv.yaml
```

## Architecture ↔ RTL mapping

| Timeloop component | Your Verilog |
|---|---|
| `MACs` (144, meshX=12) | `systolic_array` 12×12 UDP PEs |
| `WeightRegFile` | Weights stationary in each `udp_pe` |
| `InputRegFile` | Activation pipeline registers (1-cycle skew) |
| `PsumRegFile` (12-bit) | 6× `ACC_WIDTH` accumulators per PE |
| `GlobalBuffer` | On-chip activation/output SRAM (design placeholder) |
| `DRAM` | Off-chip weight/activation storage |

## UDP throughput note

Timeloop counts **144 int4 MAC units**. Each physical PE performs **6 MACs/cycle**
via UDP packing (P_w=3, P_a=2). Multiply effective throughput by **6×** when
comparing to `analyze_resnet8.py` MAC totals.

## Timeloop hierarchy (from mapper output)

```
L5  DRAM           [WIO]   Weights, Inputs, Outputs
L4  GlobalBuffer   [IO]    Inputs, Outputs (weights bypassed)
L3  DummyBuffer    []      mapping shim
L2  InputRegFile   [I]     Activations (WS: stream through array)
L1  WeightRegFile  [W]     Weights (WS: stay in PE)
L0  PsumRegFile    [O]     Partial sums + MAC compute
```
